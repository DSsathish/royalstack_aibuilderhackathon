One agent, three surfaces, one inventory

Shopper in the store

Entrance QR, live voice in English, Tamil or Hindi, aisle navigation, scan-first cart, self-checkout, verified exit.

Shopper online

The same app and the same agent in online mode, sharing the same stock, offers, points and history.

Owner

Forecasts, reorder drafts awaiting approval, demand signals, customers, offers, loss view, and an owner assistant by voice.

One canonical layer, many adapters

Signed webhooks in, a pull endpoint, signed sale events out, a scheduled CSV feed. The shop keeps its billing software; the agent reflects its stock within two seconds on every instance.

Solution overview

Three surfaces, one agent, one Firestore inventory as the stock of record, and a sync layer so the shop keeps the software it already runs on.
